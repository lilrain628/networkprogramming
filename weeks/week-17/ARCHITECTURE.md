# Архитектура (capstone)

Проект **users-s10**.

## Обзор

- Сервис пользователей за API-шлюзом; взаимодействие между сервисами по контрактам (REST/gRPC по курсу).
- Хранение и кэш — по выбранной вами схеме (в задании уточняется на защите).

## Нефункциональные требования

- Масштабирование по горизонтали (несколько реплик за Service/Ingress).
- Наблюдаемость: метрики, логи, трассировки (подключите по возможности курса).
