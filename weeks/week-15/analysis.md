# Анализ

Проект **sessions-s10**.

## Latency

- **latency** (p50): оценка задержки на критическом пути сервиса — измеряется профилировщиком или APM; для отчёта зафиксируйте фактические значения после нагрузочного теста.

## Наблюдения

- При росте нагрузки latency обычно растёт из‑за очередей и конкуренции за CPU/IO.
- Для сравнения снимайте latency на одной и той же конфигурации (одинаковый hardware, сеть, версия образа).
